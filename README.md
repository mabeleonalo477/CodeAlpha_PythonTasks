# CodeAlpha Python Internship Tasks
Python programming tasks completed during CodeAlpha internship — Hangman, Stock Tracker, and Chatbot


## 📋 Tasks Completed

| Task | File | Description |
|------|------|-------------|
| Task 1 | `hangman.py` | Text-based Hangman game with 5 predefined words and 6 incorrect guess limit |
| Task 2 | `stock_tracker.py` | Stock portfolio tracker with hardcoded prices and optional file export |
| Task 4 | `chatbot.py` | Rule-based chatbot with predefined responses |

## 🛠️ Technologies Used

- **Python 3.x**
- Standard library modules: `random`, `csv`, `re`, `requests`

## 🚀 How to Run

### Task 1 — Hangman
```bash
python hangman.py

Guess letters one at a time. You have 6 incorrect guesses before the game ends.
Task 2 — Stock Tracker
bash

python stock_tracker.py

Enter stock symbols (e.g., AAPL, TSLA) and quantities. Type DONE when finished. You'll be prompted to save results as .txt or .csv.

Task 4 — Chatbot
bash

python chatbot.py

Type hello, how are you, or bye to interact. Type bye to exit.
